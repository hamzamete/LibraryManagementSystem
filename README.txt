PROJECT TITLE:
Library Management System

COURSE:
COMP203 – Data Structures

DESCRIPTION:
This project is a console-based Library Management System developed in Java.
The main goal of the project is to understand and apply different data structures
by using them in a real-world scenario.

The system manages books in a library and supports operations such as adding,
removing, searching, borrowing, returning, and listing books.

Different data structures are used for different purposes:
- Dynamic Array is used to store and manage the book catalog.
- Binary Search Tree (BST) is used to search and list books by title in alphabetical order.
- Queue is used to manage borrow requests in a first-come, first-served manner.
- Stack is used to implement the undo feature for borrow and return operations.

The project is designed according to the given project manual and includes all
required classes and functionalities.
